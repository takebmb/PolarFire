# Glossary — PolarFire SoC Discovery Kit UG (DS50003630E)

**0P6V_VREF_DDR4 / VTT** — DDR4 終端・基準 0.6V。MIC5166、測定点 C250 (Ch1, Ch2)
**125 MHz Oscillator (X1)** — DSC1123BL5-125.0000、LVDS、±10 ppm。Bank 5 P5/P4 → MSS 基準クロック (Ch3)
**50 MHz Oscillator (X3)** — DSC1001DL5-050.0000、シングルエンド 1.8V、±10 ppm。ファブリック R18 (Ch3)
**7-Segment connector (J48)** — 10pin、Serial 7-Seg 8-Digit 基板用。Bank 0。電圧は J49 (Ch3, Ch6)
**AN5165** — 出荷時の FIR フィルタデモのアプリケーションノート (Ch4)
**Bank 0 (HSIO)** — 1.8V。LED1-7、SW、7 セグ、UART_D、50 MHz (Ch2, Ch3)
**Bank 1 (GPIO)** — VDDI1_5（2.5/3.3V）。RPi GPIO 21 本、mikroBUS、MIPI RX (Ch2, Ch6)
**Bank 2 (MSS I/O)** — 3.3V。UART_B/C、RPi SPI・ID I2C、LED8 (Ch3)
**Bank 3 (JTAG)** — 3.3V。Debug Reset (Ch2, Ch3)
**Bank 4 (MSS SD)** — 1.8V。microSD（電圧変換 IC 経由） (Ch3)
**Bank 5 (MSS SGMII)** — VDDI1_5。VSC8221 SGMII、125 MHz REFCLK (Ch3)
**Bank 6 (MSS DDR)** — 1.2V。DDR4 (Ch3)
**DEVRST_n (E8)** — 入力専用のチップ全体リセット。MCP121T-315E/TT で駆動 (Ch3)
**DirectCores** — Microchip の IP コア（IP Core Tools から入手） (Ch2)
**eFP5 (U16)** — オンボード FlashPro5。USB-JTAG による書き込み・デバッグ (Ch1, Ch5)
**FIR Filter demo** — 出荷時に書き込まれているデザイン (Ch4)
**Firmware Catalog** — MSS 用ファームウェアドライバの配布元 (Ch2)
**FlashPro Express** — `.job` で書き込むツール (Ch5)
**FT4232HL** — FTDI 製 USB-quad UART。UART_B/C → Bank 2、UART_D → Bank 0 (Ch3)
**Identify / SmartDebug** — eFP5 経由のファブリックデバッグツール (Ch1)
**J10** — Raspberry Pi 4 互換 40pin（Würth 61204021621） (Ch3, Ch6)
**J11** — Raspberry Pi MIPI RX（CSI-2 カメラ）。底面 (Ch1, Ch6)
**J12** — Debug live probes (Ch3)
**J17** — microSD（GCT MEM2075-00-140-01-A）。底面 (Ch3, Ch6)
**J3** — RJ45（マグネティクス内蔵） (Ch1)
**J4 / J7** — USB-C 5V/3A 給電 / 5V DC ジャック (Ch1, Ch2)
**J45** — VDDI1_5 の選択（1-2: 3.3V 既定 / 2-3: 2.5V） (Ch2)
**J46** — VDDAUX1 の選択（1-2: 3.3V 既定 / 2-3: 2.5V） (Ch2)
**J47** — 電源元の選択（1-2 クローズ: USB-C 既定 / 開放: DC ジャック） (Ch2)
**J49** — 7 セグ電圧（1-2: 3.3V / 2-3: 5V 既定） (Ch2)
**J5 / J6** — mikroBUS ソケットの 2 列（J5: AN/RST/CS/SCK/MISO/MOSI、J6: PWM/INT/RX/TX/SCL/SDA） (Ch6)
**.job file** — FlashPro Express のプログラミングジョブ (Ch5)
**Libero SoC** — FPGA 設計ツール。無償 Silver ライセンス。プログラマドライバ同梱 (Ch2)
**MPFS-DISCO-KIT** — 本キットの型番。基板 Rev 2 (Ch1, Ch4)
**MPFS095T-1FCSG325E (U1)** — 搭載の PolarFire SoC FPGA (Ch1)
**MSS** — Microprocessor Subsystem（SoC の CPU 側）。Bank 2/4/5/6 を使う (Ch3)
**MT40A512M16TB-062E:R (U2)** — Micron DDR4 x16、1 GB (Ch3)
**PPAT** — Package Pin Assignment Tables。パッケージ全ピンの一覧 (Ch3)
**Power LEDs** — 5P0V、VDD（1V コア）、1P8V (Ch1, Ch2)
**RUN PASSED** — FlashPro Express の書き込み成功表示 (Ch5)
**SGMII** — VSC8221 と MSS Bank 5 の間の PHY インターフェース (Ch3)
**Silver license** — Libero の無償ライセンス（Microchip Portal で発行） (Ch2)
**SoftConsole** — RISC-V 組込みソフトの IDE。eFP5 でデバッグ (Ch1, Ch2)
**SW1/SW2** — Push button（T19 / U18） (Ch6)
**SW8** — 8 bit DIP（U17, Y16, R17, AA15, AA20, Y20, V21, AA19） (Ch6)
**Test points** — GND1/GND4/GND5、TP_VDD、TP_1P8V (Ch2)
**VCCB** — 7 セグコネクタ側の電源ピン（J49 で 3.3/5V） (Ch6)
**VDD** — 1.0V コア電源。MIC22705（7A）、C144、TP_VDD (Ch1, Ch2)
**VDDAUX1** — Bank 1 の補助電源。J46 で選択 (Ch2)
**VDDI1_5** — Bank 1・Bank 5 の I/O 電源。J45 で選択 (Ch2)
**VSC8221 (U4)** — 10/100/1000BASE-T Ethernet PHY (Ch1, Ch3)
